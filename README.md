# IncuBrix Creator Studio — Interactive Web Application Prototype

An interactive, full-stack concept prototype of the **IncuBrix Creator Studio** built for the IncuBrix 2027 Growth Engineer Assessment (Option 1). It provides a polished, interactive browser application designed for a 5-minute screen-recorded product walkthrough demonstration.

---

## Important Prototype & Compliance Disclosure

> **Interactive Concept Prototype | Demo Mode**
>
> This application is a deterministic concept prototype inspired by the IncuBrix product vision, interface, and creator repurposing workflows.
> - **Zero External AI Inference:** Generation results are generated by deterministic local layout engines based on creator format rules; no external OpenAI/Anthropic/Gemini API keys are connected.
> - **Zero Live Video/Audio Rendering:** Storyboards and podcast outlines represent structural production plans, not playable media files.
> - **Zero Social API Telemetry:** Scheduled calendar posts and performance charts are saved to browser `localStorage` only; no publishing integrations (LinkedIn, Meta, YouTube) or live metrics APIs are connected.
> - **Illustrative Credit Balance:** The 300 credits balance is a sample demonstration pool and non-metered.

---

## Technologies Used

- **Framework:** React 18 (TypeScript)
- **Bundler & Dev Server:** Vite 5
- **Styling:** Tailwind CSS 3.4
- **Iconography:** Lucide React
- **Persistence:** Browser `localStorage` (seeds automatically on first launch)
- **Deployment & Building:** Standard ESNext / PostCSS / Autoprefixer

## Installation & Running

### 1. Install Dependencies
```bash
cd incubrix-creator-studio
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
The server will boot locally at `http://localhost:5173`. Open this URL in any modern browser.

### 3. Build for Production
```bash
npm run build
```
Generates an optimized, minified production bundle in `dist/`.

## Key Features

1. **Top Bar with Demo Balance & Disclaimer:**
   - Permanent indicator showing `300 credits` with `Demo balance` badge.
   - Visible banner: `"Interactive Prototype | Demo Mode"`.
2. **Dashboard with 5 Creation Modes:**
   - Stat cards: Content Workflows (5 Modes), Saved Drafts, Scheduled Posts, Available Credits.
   - Five large clickable creation mode cards: **Text**, **Audio**, **Video**, **Clips**, **Editor**.
   - Recent activity feed with sample status tags.
3. **Interactive Content Creation Studio:**
   - Format selector (Text, Audio, Video, Clips, Editor).
   - Platform options (LinkedIn, YouTube, Instagram, X, Podcast, TikTok).
   - Tone options (Professional, Conversational, Educational, Engaging, Storytelling).
   - Required topic validation with inline warning.
   - Deterministic preview generator with 700ms simulated progress spinner.
   - Format-specific outputs (scene storyboards for video, talking points for audio, hook timestamps for clips).
   - Working buttons: **Regenerate Preview**, **Copy Content**, **Save Draft**, **Open in Editor**.
4. **5 Production Templates:**
   - **LinkedIn Content:** Professional thought leadership and B2B educational carousels.
   - **Podcast Content:** Show notes, episode hooks, and structured outlines.
   - **Video Content:** Script outlines, scene-by-scene composition, and B-roll checklists.
   - **Repurpose Video:** Transforming long-form transcripts into 3 vertical 9:16 short clips.
   - **Niche Content:** Targeted developer and tech audience authority outlines.
   - 1-click "Select Template" immediately routes to the studio with prefilled inputs.
5. **Content Library:**
   - Filter drafts by format (All, Text, Audio, Video, Clips, Editor).
   - Live search by title, topic, or platform.
   - "Preview" modal to inspect stored JSON blueprint.
   - "Edit in Studio" routes back into the workspace to continue editing.
   - Full deletion and persistence to `localStorage`.
6. **Publishing Calendar:**
   - Monthly calendar grid for November 2026.
   - "Schedule New Post" modal supporting date, time, platform, and title.
   - Delete scheduled entries directly from calendar cells.
   - Clear banner: `"Demo scheduling only — posts are not published to external platforms."`
7. **Analytics ("Coming Soon"):**
   - Professional SaaS interface explaining that live publishing and audience APIs are disconnected.
   - Clear illustrative sample charts with no fabricated metrics.
8. **Settings & Workspace:**
   - Illustrative credit pool details, workspace configurations, and technical architecture notes.

## Step-by-Step 5-Minute Demonstration Walkthrough

Follow these exact steps during a screen-recorded demonstration:

### Flow A: Dashboard to Custom Text Creation
1. Start on the **Dashboard** (`http://localhost:5173`). Highlight the **Demo Mode banner** and **300 demo credits** pill in the top bar.
2. Review the 4 stat cards and note that 4 sample assets are seeded.
3. Click the **Text** card under "Choose a Creation Mode".
4. Enter Topic: `The 3 Pillars of AI Creator Operations`.
5. Target Audience: `Solopreneurs and video creators`. Platform: `LinkedIn`. Tone: `Professional`.
6. Click **Generate Preview**. Observe the brief loading sequence.
7. Inspect the generated **Headline**, **Opening Hook**, **Main Caption**, and **Recommended Hashtags**.
8. Click **Save Draft**. Notice the green floating toast notification.

### Flow B: Template-Driven Podcast Script
1. Navigate to **Templates** on the sidebar.
2. Review the 5 cards. Click **Select Template** on **Podcast Content**.
3. Notice that the Create Content page is automatically pre-filled with the episode title, conversational tone, and podcast platform.
4. Click **Generate Preview**.
5. Inspect the generated **Intro Script**, **Talking Points**, **Outro Script**, and estimated duration.
6. Click **Save Draft**.

### Flow C: Repurposing Video into Short-Form Clips
1. Navigate back to **Templates** and click **Select Template** on **Repurpose Video**.
2. Notice the Content Format switches to **Clips** and Platform is set to **TikTok**.
3. Click **Generate Preview**.
4. Examine the 3 simulated vertical short-form clip cards, complete with simulated timecode ranges (`01:45 – 02:28`), hooks, and captions.
5. Click **Copy Clip** on Clip 1, then click **Save Draft**.

### Flow D: Content Library Inspection & Editing
1. Navigate to **Content Library** on the sidebar.
2. Observe your newly saved drafts appearing in the table alongside the 4 pre-seeded demo records.
3. Type `Podcast` in the search box to filter results in real time.
4. Click **Edit in Studio** on one of the items. Verify that it reloads all parameters into the Create Content workspace.
5. Make a small edit to the topic and click **Save Draft**.

### Flow E: Scheduling Content to the Calendar
1. Navigate to **Calendar** on the sidebar.
2. Review the scheduled post cards on the November 2026 grid.
3. Click **Schedule New Post** in the top right.
4. Enter Title: `Creator Operations Masterclass Drop`, Platform: `YouTube`, Date: `2026-11-27`, Time: `14:00`.
5. Click **Save to Calendar**.
6. Verify the post appears immediately on November 27th.
7. Point out the clear disclaimer stating that external publishing APIs are disconnected in this prototype.

### Flow F: Reviewing Analytics & Settings
1. Click **Analytics** on the sidebar.
2. Show the "Analytics — Coming Soon" banner and explain the product architecture rationale for keeping social media APIs disconnected in the concept build.
3. Click **Settings** to show the 300 credits illustrative balance explanation and local storage mode.
